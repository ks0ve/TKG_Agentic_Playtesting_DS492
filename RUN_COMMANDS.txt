RUN COMMANDS (PowerShell, from the project folder)
=====================================================

FIRST-TIME SETUP (once per machine; needs git, uv and Ollama installed)
git clone https://github.com/ks0ve/TKG_Agentic_Playtesting_DS492.git
cd TKG_Agentic_Playtesting_DS492
git clone https://github.com/BlueLinkX/SAGE external/SAGE
git -C external/SAGE checkout 24de803f33123d16fe6f7cfa0062f3c81217a978
uv venv --python 3.10 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
ollama pull qwen2.5:7b
.venv\Scripts\python.exe -m pytest          (should say 44 passed)

Mac/Linux: replace  .venv\Scripts\python.exe  with  .venv/bin/python  everywhere,
and set the API key with  export ANTHROPIC_API_KEY="sk-ant-..."

Before long runs: turn off Ollama auto-update (tray icon -> Settings).
Ctrl-C stops any run cleanly and still writes its summary.
Results go in runs\<timestamp>_<agent>_<task>_seed<N>\  (headline numbers: summary.json)


--- FREE (local Ollama, needs the Ollama app running) ---

1) Pilot, 50 steps (~10 min)
.venv\Scripts\python.exe -m react_baseline.run --agent react --llm ollama --seed 0 --max-env-steps 50 --out-dir runs/pilot

2) Check the pilot (use the folder name printed by step 1). Continue only if it says PILOT PASSED.
.venv\Scripts\python.exe -m react_baseline.pilot_check runs\pilot\<folder-from-step-1>

3) Full run, 3 seeds x 300 steps (~3.5 hours)
.venv\Scripts\python.exe -m react_baseline.run --agent react --llm ollama --seeds 0,1,2 --max-env-steps 300

4) Random baseline (seconds)
.venv\Scripts\python.exe -m react_baseline.run --agent random --seeds 0,1,2 --max-env-steps 10000

--- PAID: Claude Haiku via the API (uses Anthropic Console credits) ---

Set the key (lasts until you close this terminal):
$env:ANTHROPIC_API_KEY = "sk-ant-..."

Pilot with a spending cap (stops at 100k tokens):
.venv\Scripts\python.exe -m react_baseline.run --agent react --llm anthropic --seed 0 --max-env-steps 50 --max-tokens 100000 --out-dir runs/pilot

Full run with a cap:
.venv\Scripts\python.exe -m react_baseline.run --agent react --llm anthropic --seeds 0,1,2 --max-env-steps 300 --max-tokens 2000000
